## 本机整合原生边界

`fixed_proxy.rs`：只调用捆绑的 Python 适配器及固定安装位置；JSON 白名单摘要不包含原始配置或凭据。完整检查、受保护启动、一次性修复计划/确认均在原生端实施，超时终止本次子进程树。只有退出状态及响应协议确认成功的启动/修复才释放 job；失败时终止子树并等待实际进程句柄退出，保留成功启动的程序；共享 Cleaner 锁防止身份事务与启动/修复重叠。桥接以原因码返回已知失败（找不到 Proxy-v2、版本不符、缺 Python 组件、策略无效），原生端给出对应提示，其余保持「桥接异常退出」；启动和浏览器门禁的超时预留了等待守护恢复（最多 60 秒）的时间。

网页版入口 `Entry::Browser` 先过 `check-browser`，再交给 `browser::open_gated` 以门禁给出的专用端口启动；不再有专用 Chrome 启动或资料绑定。只读动作 `connections`（连接快照）不加互斥；`protect`（Proxy-v2 `-Protect`，Windows 自己弹管理员确认）加互斥、330 秒超时、不保留子进程。`exit_timezone` 供浏览器同步启动路径读取已缓存的出口时区（`block_on`，测试覆盖阻塞任务与普通线程两种调用）。`proxy_account` 只返回当前登录邮箱。

`fixed_proxy_tests.rs`：临时 Python 子树回归，覆盖内部修复超时、非零退出、无效协议、失败动作的退出等待和成功启动保留；指纹浏览器独立门禁与时效校验；连接快照、保护结果和旧网页版动作的协议校验。

`main.rs`：独立应用标识；不注册上游自动更新，不随宿主自动启动浏览器。Windows 明确 `--browser` 才走受保护浏览器入口；每次启动把自身路径写入应用数据目录的 `browser-entry.json`，供 Proxy-v2 登录链接启动器交接。只注册界面实际调用的命令。上游更新测试仍仅作密码学回归，不代表启用了更新。

`tray.rs`：托盘经桥接每 30 秒读取守护状态（只读，不做完整检查），故障和恢复各发一次 Windows 通知；托盘启动（含网页版=指纹浏览器）与首页共用 `fixed_proxy::launch` 门禁。release 版首次启动写入 HKCU Run，带 `--tray` 开机在托盘待命，菜单可关闭。

`cleaner_identity.rs`、`identities/archive.rs`、`identities/store.rs`：完整 settings 归档剥离本机网络字段，清空/恢复原子保留当前字段，拒绝恢复旧代理。身份事务后完整复查；恢复未完成时整合入口不放行。

`regions.rs`：13 项目录不扩展；`target` 把「目录地区时区 + en-US」识别为旅居者目标，只核对浏览器语言，不要求系统语言属于该地区。

# src/
> L2 | 父级: ../CLAUDE.md
清理与身份事务在本机执行；没有网络部署或 SSH 命令。生产命令提供身份压缩暂存、空身份切换、恢复与独立确认的直接删除；原有批量清理事务只保留测试样本。用户选择保留或随身份暂存，系统设置独立。
identities/ - SQLite 身份目录、用户保留策略、加密压缩暂存、空身份切换、恢复与选择性直接删除；见其 CLAUDE.md。
cleaner_identity.rs: 身份目标与保留策略适配；测试显式断言规范源路径，复用白名单、完整快照与窄 JSON 键操作，不扫描源码。
updater_tests.rs: 官方更新器本机 HTTP 公开向量验证篡改与版本冒用；发布显式传入实际清单/归档，下载核验而不安装。
main.rs: Tauri 生命周期、双语托盘、单实例与 `--browser`/`--tray` 入口、浏览器入口登记，只注册固定出口/身份/CLI/系统读取与时区定位/浏览器读取与启动/界面语言命令；发布缺少 custom-protocol 时编译失败；Windows 正式宿主使用 GUI 子系统。
ui_language.rs: 受 zh/en 白名单限制的界面偏好，原子持久化后发布内存状态；共用托盘菜单，独立于电脑与浏览器语言。
browser/: 指纹浏览器、资料与缓存边界、真实浏览器回报及目标地区环境核验；见其 CLAUDE.md。
windows.rs: 当前用户 SID/文件所有权、Win32 直接读取时区/语言、缓存系统版本、时区写入与定位关闭；控制台工具隐藏窗口，外部链接；拒绝凭据管理器自动读取和 SSH 操作。
windows_timezones.rs: CLDR 48 固定全量 Windows/IANA 映射与目录别名，无运行时下载或猜测；原始许可证作为 Windows 资源交付。
windows_process.rs: 当前用户 Toolhelp/MSIX 固定 Claude 包族与精确 CLI 参数识别、创建时间和句柄复核、独立资料的正常窗口关闭；原始参数不序列化，超时子进程使用 Job Object；Windows CI 回归实际映射时区写入后还原。
system.rs: 电脑环境读取、时区写入与关闭定位（首页使用）；后台执行原生操作，错误后重新读取系统状态。
native.rs: 进程编号、凭据列表与 JSON 解码桥；身份快照/恢复仅原生可用，默认服务正文不送 UI；凭据删除只供测试样本。
cleaner.rs: 进程识别与精确停止（身份切换、CLI 管理共用）、Windows 外置 AppData 白名单与规范路径复核；原有全机扫描/批量清理只剩测试样本使用，不再注册为命令。
claude_cli.rs: 内嵌脚本的只读状态与 CLI 程序卸载/重装，登录终端加载 nvm 环境，固定动作与原生互斥锁限制修改；真实阶段沿用进度通道，超时结束本次子进程组或 Job Object；Windows 完成时先回收本次子进程树再读取完整协议，成功要求完整回报；临时目录测试清空继承环境并在 zsh 启动后固定样本 PATH，验证版本、卸载、资产保留和失败不报成功，不能探测或卸载真实安装。
cleaner_folder.rs: 用户所选目录内的 Claude 白名单发现；不跟随链接、不扫描目录外、不处理项目权限或凭据。
progress.rs: 有序脱敏阶段事件与有界内存日志；供清理与浏览器共享，只读取事务传入的计数和状态。
cleaner_transaction.rs: 仅 cfg(test) 的历史快照/删除样本回归；不编译进生产身份事务，不注册永久清理命令。
cleaner_targets.rs: Claude 白名单、桌面登录存储子目录（不删整个应用资料目录）、完整目录规模和元数据指纹（无时间/条目截断，读取失败不生成可删除快照）、按 Windows 实际 AppData 的旧组织会话检索；不进入链接目标或项目源码。
cleaner_config.rs: 账号缓存和代理认证配置的窄范围变换；保留其他配置并只返回键名。
cleaner_io.rs: 清理后配置原子写入；Windows 写入前保留原所有者/DACL，临时文件仅保存新内容，失败移除，不保留原配置。
cleaner_tests.rs: 临时白名单/快照/日志验证，覆盖超过 30,000 文件的完整清理与权限失败保护；官方原生版本路径、自编译并经启动握手的可丢弃进程与 Node 样本验证身份、终止与其他 Node 保留；Windows 子进程隔离的外置 AppData 验证白名单和身份目标，不复制系统平台二进制，不修改用户数据。
regions.rs: 13 项地区目录、出口地区匹配与浏览器核验目标（含旅居者组合）；目录与本机时区验证。
linux.rs: Linux procfs 当前用户进程、zoneinfo/timedatectl、GNOME 定位偏好、GNOME/KDE 设置入口与 Wayland/X11 剪贴板；LC_MESSAGES/LC_TIME 分别读取会话语言/区域格式，不匹配时先报手动操作再改时区；未知定位为 null，Linux 钥匙串明确不可用；不将系统代理凭据序列化给 WebView。
